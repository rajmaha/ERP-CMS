# ERP CMS - Project Summary

## ✅ Core Features

### Authentication
- JWT-based login/register
- Role-based access (Admin/User)
- Profile & password management

### Admin Panel
- Dashboard with statistics
- Complete CRUD for all modules
- Responsive sidebar navigation

### Content Management
- **Home Page**: Hero, features, commitments, stats, CTA
- **About Page**: Mission, vision, values, why choose us
- **Pages**: Dynamic page builder with SEO

### Media & Gallery
- File upload with drag & drop
- Media grouping with icons
- Photo/video gallery with categories
- Image picker with filters

### Business Modules
- Products, Portfolio, Testimonials, Clients
- Multiple images support
- Rich text editor

### Communication
- Contact form with SMTP
- reCAPTCHA integration
- Message management

### Settings
- Site configuration
- SEO & Open Graph
- Social media links
- SMTP & reCAPTCHA setup

## 🚀 Quick Start

```bash
# Backend
npm run dev

# Frontend (new terminal)
cd client && npm start
```

**Admin:** admin@example.com / admin123

## 📊 Modules
Users, Pages, Products, Portfolio, Testimonials, Clients, Gallery, Media, Menu, Contact, Settings

## 🔐 Security
JWT auth, bcrypt, rate limiting, input validation, XSS protection

## 🎯 Tech Stack
**Backend:** Node.js, Express, MongoDB  
**Frontend:** React, React Router, Axios  
**Other:** Multer, Nodemailer, JWT
